Build a Task Tracker

Project goal:

This is a simple menu-based Python program for keeping track of tasks. Tasks are saved in a JSON file so they can be loaded again when the program runs later.

Features

- Add a task with a title.
- View tasks with their numbers and status.
- Mark a task as Done.
- Delete a task.
- Save tasks in tasks.json.
- Load saved tasks when the program starts.
- Handle empty task titles, invalid menu choices, invalid task numbers, and a missing tasks file.
Requirements
- Python 3
- No extra packages are needed.

How to run:

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run python mini_task_tracker.py.
4. Choose an option from the menu.
5. The program creates tasks.json in the same folder when tasks are saved.
